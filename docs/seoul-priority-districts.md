# Seoul priority development districts

## Approved scope

The project owner selected these eight priority districts on 2026-11-26.
The list is a scope selection, not a ranking or a geographic boundary definition.

| District | Candidate focus (not yet approved individually) |
|---|---|
| Banpo (반포) | Raemian One Bailey (explicitly selected for special treatment), Acro River Park, Raemian One Pentas |
| Seongsu / Seoul Forest (성수·서울숲) | Trimage, Acro Seoul Forest, Galleria Foret |
| Jamsil (잠실) | Lotte World Tower, Lotte World Mall, Lotte World, Seokchon Lake |
| Yeouido (여의도) | Parc.1 towers (initial custom facade implemented), IFC, 63 Building, FKI Tower, LG Twin Towers |
| Samseong / Teheran-ro (삼성동·테헤란로) | Parnas Tower, Trade Tower, COEX, Gangnam Finance Center |
| Apgujeong / Cheongdam (압구정·청담) | PH129, Eterno Cheongdam, Galleria, luxury retail facades |
| Dogok / Tower Palace (도곡동·타워팰리스) | Tower Palace complex, surrounding skyline |
| Yongsan / Sinyongsan (용산·신용산) | Yongsan Prugio Summit, Amorepacific HQ, Raemian Caelitus, Yongsan Station |

## Design principles

- Preserve 1:1 scale and mapped footprints and heights.
- Preserve the district's overall skyline, roads, riverside and building arrangement.
- S+: individually modeled facade and usable empty floor spaces, including penthouse where applicable.
- S: individually modeled facade, principal structure and empty floors where appropriate.
- A: preserve recognizable geometry, colors and characteristic facade patterns.
- B: ordinary compact building generation.
- C: simplified small and auxiliary buildings.
- Empty buildings should appear illuminated at night; no Shanghai-style architecture, arbitrary neon or forced media facades.
- The remaining Seoul area is still part of the citywide world; priority districts do not limit generation coverage.

## Open decisions

- Exact geographic polygons and cross-boundary handling.
- Final list and grade of each building or complex, including individual tower selection.
- Authoritative sources for mapped identities, geometry and floor counts.
- Performance budgets and measured in-game acceptance criteria.
- No district-specific runtime rules are implemented by this document.
