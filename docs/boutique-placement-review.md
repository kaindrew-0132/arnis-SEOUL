# Boutique geographic placement review
Three third-party OSM way hints from Mapcarta are explicitly unapproved; never write them into osm_identity until matched to the raw current geometry and address/occupancy. The bounded Cheongdam/Apgujeong query requests building ways/relations, shop nodes and named highway ways once from a public Overpass endpoint. Data © OpenStreetMap contributors, ODbL 1.0. No retries or persistent external polling. Extract is a CI artifact, not checked into the repository.
The planner compares exact brand aliases, exact address and supplied third-party IDs on closed whole-building ways. It projects polygon edges into approximate local metres and reports up to five nearest edges to the exact named street, lengths, outward bearings and preview width fit. It is intentionally review-only: no approved coordinates, placement or world writes. Nearest-road distance is not proof of storefront direction, and straight segments may fragment a long facade; multipolygon outlines and separate building parts still need review. Site occupancy, time validity, full building height, orientation, entrance and safe collision checks are required before approving a placement. The existing association script provides separate POI-to-building evidence. Do not deploy if download fails, Overpass returns a remark, or input is incomplete.
