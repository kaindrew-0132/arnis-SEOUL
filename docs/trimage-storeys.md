# Trimage tower-specific empty storeys
S+ remains the priority for all four towers. The published building-register summaries identify 101/102/103/104 as 47/46/45/47 above-ground storeys respectively (https://chungyakalji.com/complex/A10026988 ; https://juso.zzxxccvv.com/a/서울/성동구/왕십리로/16). Height numbers from other public references disagree; this implementation retains mapped height and footprint and does not claim measured floor elevations. No furniture, private room plans, or fabricated penthouse layout. The entire mapped height is distributed evenly in integer block rows, including the top floor. The count is applied only to ground-level matching towers with at least three blocks per storey; otherwise the previous uniform grammar is retained. The existing name/height/Seoul guard is unchanged and OSM identity still needs actual dataset verification.
Each intermediate slab and white facade band uses the same integer schedule. The existing invisible lighting stays below slabs. Other landmark profiles and ordinary buildings retain their prior floor generation. Rust tests cover all four counts, minimum headroom, corner piers, band alignment and insufficient-height fallback. Exact facade curves, structural cores, real crown and penthouse levels, separate tower footprint verification, and actual in-game checks are still outstanding.
